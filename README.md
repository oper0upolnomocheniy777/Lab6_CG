# 3D Polyhedron Visualizer - Enhanced GUI

Расширенный 3D визуализатор многогранников с современным графическим интерфейсом.

## 🚀 Основные возможности

- **5 Платоновых тел**: Тетраэдр, Куб, Октаэдр, Икосаэдр, Додекаэдр
- **Интерактивный GUI**: Кнопки, слайдеры, панели управления
- **Управление мышью**: 
  - Перетаскивание для вращения
  - Колесо мыши для масштабирования
  - Правая кнопка для сброса
- **Два типа проекций**: Перспективная и аксонометрическая
- **Режим автоматического вращения**
- **Матричные преобразования**: Масштабирование, вращение, отражение, сдвиг
- **Реальное время**: Плавная анимация и отклик

## 🎮 Управление

### Мышь
- **Левая кнопка + перетаскивание**: Вращение
- **Колесо мыши**: Масштабирование
- **Правая кнопка**: Сброс вида

### Клавиатура
- **1-5**: Выбор многогранника
- **P/A**: Переключение проекций
- **R**: Сброс преобразований
- **Space**: Авто-вращение
- **H**: Справка
- **ESC**: Выход

### Интерфейс
- Используйте кнопки для быстрых преобразований
- Слайдеры для точной настройки параметров
- Панель управления для доступа ко всем функциям
